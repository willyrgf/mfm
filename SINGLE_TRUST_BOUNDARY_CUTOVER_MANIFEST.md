## Scanner policy

The final source scan is literal- and path-scoped. It scans production, tests, fixtures,
migrations, metadata, tasks, and documentation; only this manifest and the two immutable source
documents are excluded. Generic iterator collection, ordinary domain collections, SQL joins,
thread joins, fact-selection barriers, provider observations, wallet reservations, database
credentials, public closed status, and legitimate protocol authorization are not deletion targets.
Every newly discovered alias, Serde spelling, SQL identifier, feature, DTO, or fixture is appended
here with one named owner before it is removed.
