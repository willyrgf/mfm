# Persisted And Public Surfaces

Status: review inventory for the typed-core no-secret invariant.

This inventory lists surfaces that persist data or return public data to users. It is not runtime
authority by itself. The authoritative contracts remain `docs/design.md`, certified specs, typed
events, store admission, runtime verification, replay verification, and artifact role contracts.

Allowed data classes below are intentionally narrow. Anything outside the allowed class requires a
design update before it becomes a persisted or public surface.

## Intentional Local Bearer Output

`mfm keystore tx-sign --out` writes a raw signed transaction only because the user explicitly asks
for local bearer material. That output is outside typed-run persisted/public surfaces. It must not
be copied into typed configs, events, artifacts, public outputs, replay fixtures, diagnostic
artifacts, REST bodies, or app status responses.

The command remains subject to ordinary local CLI handling: do not log the signed payload, do not
persist it in MFM run stores, and keep error messages on the public-safe error boundary.
