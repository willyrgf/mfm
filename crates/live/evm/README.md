# mfm-evm-live

The EVM adapter owns bounded provider ingress, protocol authentication, committed-call binding,
nonce authority, signing, and raw-response disposal. `EvmLiveAssembly` registers the finite exact
descriptor closure into one catalog-wide Runtime. A binding must match the stable adapter identity,
physical target, State/capability role, nonce effect domain, and (for broadcast) public signer key
instance before any provider, signer, or nonce handle can enter.
