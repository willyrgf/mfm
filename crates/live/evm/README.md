# mfm-evm-live

The EVM adapter owns bounded observational provider ingress, protocol authentication,
committed-call binding, and raw-response disposal. `EvmLiveAssembly::install` validates and
registers the finite exact Portfolio Read closure into one catalog-wide Runtime, then retains only
the secret-free planning bindings. A binding must match the stable adapter identity, physical
target, and State/capability role before a provider can enter. Balance Reads also compare the
secret-free route retained in the committed intent with that descriptor's physical target.
