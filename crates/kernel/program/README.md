# mfm-program

Program owns opaque State/Match documents, callback-free catalog construction, exact content
identity, and catalog-branded non-Clone typed values. Its finalized catalog is the sole issuer of
exact nominal-contract, schema-descriptor, Rust-type, and capability intent/evidence/mode
associations. Access declarations own the full immutable binding descriptor. A schema match, `ProgramRef`,
or independently finalized content-equal Program cannot qualify a value. Retained canonical bytes
decode once through the same association. Program owns no history or live I/O.
