# mfm-journal

Journal owns one exact canonical frame encoder and qualifier. Frames contain admission, fused Pure
conclusion, or fused Read intent/evidence/outcome conclusion plus an exact sorted frame-local object
closure. Recursive heads hash exact bytes with `content:sha256-v1`.

`EncodedRunFrame`, opaque `StoredRunBytes`, qualified `JournalHistory`, borrowed record/object views,
four format constants, and `frame_head_digest` are the complete surface. There is no raw parser,
open wire DTO, preparation record, occurrence/call ID, independent record digest, or portable codec.
