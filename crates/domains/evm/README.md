# mfm-evm

The EVM domain owns trusted submission planning, final Program authoring, stable State contracts,
and secret-free cumulative submission/balance contexts. Submission reserves a wallet nonce, derives
one candidate, broadcasts it, then requires receipt, finalized-head, and canonical-inclusion Reads
before exposing its frozen execution disposition. Balance work carries checked chain/anchor/asset
data through a full-context native/token Match and consolidates one common-anchor collection.
Live transport, nonce authority, and signer custody remain adapter responsibilities.
